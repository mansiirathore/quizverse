# quizverse

📚 QuizVerse
QuizVerse is a fully functional and dynamic web-based quiz platform. It allows users to create, take, and manage various types of quizzes, including:
📝 Multiple Choice Questions (MCQ)
✅ True / False
⏱ Timed Quizzes (with per-question timer and time tracking)

🚀 Features
Create quizzes with dynamic question patterns based on quiz type
Support for correct answer selection and custom marks per question
Time per question input for timed quizzes
Responsive and intuitive UI/UX (Dark theme)
Take quizzes and get instant visual feedback
View total score, correct/wrong answers, and time taken
Save quizzes locally in the browser (localStorage)
Edit and delete saved quizzes
Persistent quiz list even after page reload

📦 Tech Stack
HTML5
CSS3 (custom dark theme)
JavaScript (Vanilla)

💡 Future Improvements
User login and database support
Leaderboard and analytics
Export/import quizzes
Shareable quiz links
